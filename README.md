# Lucid — A Slack Bot

This slack bot will do basic tasks you ask with commands

## How I built it?

I was very interested in building a slack these things were new to me, i built this by learning basic coding

## The commands

I have programmed a lot of commands, /lucid-ping - pings
/lucid-help     - shows commands

/lucid-catfact  - cool cat facts

/lucid-joke     - tells a joke

/lucid-fact     - gives fun fact

/lucid-weather  - weather report

/lucid-cat      - gives a cat image of the day!

/lucid-space    - Space info of the day

/lucid-greet    - greets

/lucid-food     - shows a delicious food image

/lucid-lol      - lol

/lucid-memes    - it gives a fricking meme

My favorite command is /lucid-space, because i love spacee
